# First steps

A short guide to quickly run and verify the project.

## 1. Clone repository

```bash
git clone https://github.com/novaaurelis/ai-agents-site.git
cd ai-agents-site
git checkout mvp/clone-openclaw
npm install
```

## 2. Run in dev mode (macOS / Linux)

```bash
npm run dev
# open http://localhost:3000
```

## 3. Docker (alternative)

You can add a simple Dockerfile for production image. Example:

```Dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --production
COPY . .
RUN npm run build
CMD ["npm","start"]
```

## 4. Quick checks

- Open homepage and verify Hero, Popular models, and Modules sections.
- Open /en/terms, /en/privacy, /en/offer and verify contact e‑mail openclaw.ai@ya.ru.
