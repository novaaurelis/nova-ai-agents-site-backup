# Установка и запуск

Краткое описание: быстрый набор шагов для установки проекта, запуска локальной среды и проверки работоспособности.

## Требования

- Node.js >= 18
- npm или yarn
- Доступ к интернету для скачивания зависимостей

## Шаги установки

1. Клонируйте репозиторий

```bash
git clone https://github.com/novaaurelis/ai-agents-site.git
cd ai-agents-site
git checkout mvp/clone-openclaw
```

2. Установите зависимости

```bash
npm install
# или
# yarn install
```

3. Запуск в режиме разработки

```bash
npm run dev
# открыть http://localhost:3000
```

## Проверки после запуска

- Главная страница доступна
- Страницы модулей рендерятся
