# Installation & run

Short description: step-by-step installation for macOS, Windows and VPS, plus Telegram integration.

## Requirements

- Node.js >= 18
- npm or yarn
- Internet access to install dependencies

## Quick steps

1. Clone the repository

```bash
git clone https://github.com/novaaurelis/ai-agents-site.git
cd ai-agents-site
git checkout mvp/clone-openclaw
```

2. Install dependencies

```bash
npm install
# or
# yarn install
```

3. Run in dev mode

```bash
npm run dev
# open http://localhost:3000
```
